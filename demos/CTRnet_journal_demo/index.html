Sound Demo of CTRnet and PuLSS on CHiME-6 Corpus


We provide a sound demo based on the test set of the CHiME-6 corpus. For technical details, please refer to the following paper:

Z.-Q. Wang and S. Cornell, "Cross-Talk Speech Reduction, by Separation, for Separation", in submission, 2026.
We provide three demos (click to open the page):
• Sound Demo of CTRnet using oracle speaker diarization
• Sound Demo of PuLSS using oracle speaker diarization
• Sound Demo of PuLSS using estimated speaker diarization
