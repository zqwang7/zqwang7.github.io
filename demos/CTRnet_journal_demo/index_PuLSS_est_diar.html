Sound Demo of PuLSS with estimated speaker diarization on CHiME-6 Corpus


We provide a sound demo based on the test set of the CHiME-6 corpus. For technical details, please refer to the following paper:

Z.-Q. Wang and S. Cornell, "Cross-Talk Speech Reduction, by Separation, for Separation", in submission, 2026.
This demo presents the results of PuLSS with estimated speaker diarization (diarization results are from the USTC system).

Note:
• The spectrogram of each separated signal is masked using estimated speaker-activity timestamps, resulting in pure black regions in the spectrogram.
• There are four speakers, so there are four separated signals by each algorithm.
• PuLSS clearly outperforms GSS and mixtures. It better separates the mixed speekers..
• Firefox/Chrome is recommended.
